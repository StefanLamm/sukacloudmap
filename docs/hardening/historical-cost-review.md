# 历史支出去重核对

2026-11-12，按本轮用户确认更新。该核对用于历史成本控制，不改写原始表、业务数据库或门店拼车报价。

## 已确认规则

按「配送日期＋车牌」分组，每组只取原始来源首行的支出。后续行即使金额不同也不再累加；所选首行及其他行全部保留可追溯记录。文件顺序固定并写入结果，同一来源按原始行号升序，不以金额大小或配送线路选择。

支出中的195,5和1317,5按用户确认解析为195.50和1317.50元，不把逗号当千位分隔符。首行缺失或无效时不拿后续行补齐，完整总额显示未完成；零支出有效。不同日期或不同车牌分别计费，车牌缺失不自动合并。收入不参与成本计算。

12185条原始配送记录合并为1745个车日费用组，另外10440行不重复加支出，配送件数不受影响。141个同组多金额情况按确认的首行处理，10行逗号小数已按确认解析；本轮所选首行均有有效金额，没有未决费用组。

有1624组的全部门店均在已确认的安徽/江苏归仓范围，支出合计1,321,048.60元。另有106组同时含已归仓与待归仓门店，15组全部在当前试用范围之外。不能把106组整车费用只算到其中已归仓的门店，也不能将1624组的小计直接与全部11919票试用需求比较。当前两仓全量历史成本仍不提供一个假定拆分后的合计。

这些是历史整车支出，不是门店未来拼车每件报价。现有规划仍使用模拟道路，不能据此宣布实际节省金额；没有把历史整车成本写入每店共配单价。

## 代码、验证与来源

执行 `.venv/bin/python scripts/reconcile_historical_costs.py` 可只读复算；默认输出 [完整核对记录](historical-cost-review.json)。记录含文件优先顺序、来源摘要、逐车日所取首行、全部原始费用观察和月度汇总。输出路径不能覆盖所读取的源表。

[19项专项测试](historical-cost-tests.txt)全部通过，覆盖重复行、跨日跨车、首行差异、原始顺序、显式逗号小数、零值、空值、无效金额、缺车牌及部分归仓范围。又以独立代码直接读取五份源表的日期A列、车牌B列和实际费用列，逐一核对1745组首行引用及金额，月度与总计一致，见 [独立原表复核](historical-cost-validation.json)。该脚本未调用抽取/去重计算函数；五份文件SHA256均与之前一致。
