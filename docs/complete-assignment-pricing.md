# 完整原生分配优先核价（性能开关未采用）

`complete_assignment_pricing` 是独立的实验时序开关。裸类及显式空实验字典默认关闭；被拒绝bf58/app92a曾在daily开启。按7ba非采用规则，新功能源appd2e正常daily关闭它及其余四性能位。300/2000真实页面均完成自身原始+同选中回执回放审计，不借旧候选证据；这只证明关闭状态下的功能接入。关闭时沿用普通候选流程，实验启用时返回后优先交完整分配身份；C++ callback仍不核价或查网络。

完整分配通道直接使用求解返回的全部 `best_specs`，不受普通第一 10000 条候选池影响。主入口、Hybrid、轮转和联合邻域均转发同一开关。为返回后的核价显式保留该次原生 allowance 的 15%，最多 0.5 秒；这属于原预算内的时间分配，实际值记在 `native_time_reserve_seconds`。

Python 首先验证实际车不重复、任务不重叠且属于当前 scope，然后使用当前实测标量及原业务报价一次紧凑核价。有效必送线路保留，可选线路仅在实际专车费用低于其共配机会成本时进入整组比较；其余可选任务仍按原共配规则付费。紧凑核价不调用道路接口，缺测不缓存为永久不可配送。

整组提案覆盖必送任务时只调用一次 host.consider，由原来的完整道路物化和独立约束校验决定能否更新实际 incumbent。局部报价组争用外部线路车辆或仍缺必送覆盖时，调用一次全局物理车选线，与完整 incumbent 比较。整票、同仓、兼容报价、容量、经营时间、等待卸货、区域附加费、实际车一天一趟和不计返仓规则均保持。

已完成的 host 完整实际改进会在后续普通批次或局部时限停止前留在 host.best。联合邻域的局部解必须再和冻结外部线路合并并通过整单 proof 才能发布；不会把局部已改善误称为整单已改善，也不会越过取消和总等待截止补道路。

诊断分别记录 assignment 次数、compact 核价及实际 proof 的耗时、有效/拒绝/缺测线路、必送覆盖、外部车冲突、consider/全局选择次数、完整性变化和直接实际降费。原生罚分仍不作为真实费用。合成 oracle 和 mock 用于核查调用顺序、唯一车辆、覆盖、取消及 incumbent 保护，不能替代真实配送日收益验收。

若完整实际改进刚被接受，随后 selector 或 after_accept 因局部预算、取消或总等待截止抛出 StopSearch，最终 assignment record 随同原异常传回原生生成器，记录已发生的真实降费且继续原停止行为；不补核价、不补道路。发布遇到全局取消或等待截止时，不以较早的局部停止原因覆盖它。此修订之前的 Snapshot v1 在这一特定异常分支可能少记 Native 子统计；父 round 的完整实际费用仍是真实结果，不受该统计缺口影响。

全局 CANCELLED/WALL_BUDGET 发生后，不再为局部 scope 启动 after_accept 的新整单 proof；局部已核查并不等于整单已核查。联合邻域 publish 入口先检查外层全局控制，即使线路都在 raw 缓存，也遵守这一门禁。全局停止异常附带已产生的 native/assignment diagnostics，不再走普通候选或道路；主原生与 hybrid host 将其保留到日志，联合/轮转异常分别带 `joint_reoptimization_diagnostics` / `candidate_expansion_diagnostics` 交给外层记录。较早的局部预算停止仍可在全局预算有效时保护已证明的完整改进。

`scripts/find_unpriced_native_routes.py` 只读冻结输入、道路、原生流和价回执，找出当前实测下可行、具有单线经济价值但没有对应成功价回执的订单顺序。它排除已在其它实际车上核价的同顺序，以及已存在更低费同覆盖顺序；可绑定原 run/stream hash，并对少量候选独立审计。原流没有完整 PRICE_REQUEST/REJECTED 或完整返回 assignment 标记时，只能定位“原生出现→成功核价回执缺失”的边界，不能断言没有送核价、不能推断属于 best assignment，也不能声称该机制已导致 V5 真实漏解或整单实际节省。

正确 native-production 搜索政策下的同源单开关开发补核，使用两个已见输入、60 秒计算/195 秒总等待、seed 0/1、固定 PYTHONHASHSEED=0。该开关相对关闭的逐 seed 整次费用差为：9 月开发输入 -389.32 / -262.46 元，已知 225 店输入 -24.53 / -6.97 元；普通双 seed 中位差分别为 -325.89 / -15.75 元。两输入道路不同，不合计为整单节省或通用节省率，也不能把整次差额全部归为 assignment 阶段直接 gain。[完整开关结果与采用边界](general-delivery-improvements.md)。
