# Astryx 界面改造与验收

2026-11-14，本轮在 `test` 分支基于 v0.16.0 开发，采用用户选定的暖中性色与橙色品牌。只更新本机测试快照；不发布新版本、不合并 main，不开启外网入口。

## 界面范围

- 登录与会话恢复、桌面侧栏、手机导航抽屉、共享工作区、账号管理、操作记录。
- 仓库、门店、车辆和报价资料：列表、筛选、分页、导入、批改、位置编辑及版本弹窗。
- 每日需求、分组、资源安排、校验、快照、方案规划、人工调整、历史和导出。
- 地图检索、选点、缩放、全屏、错误与加载状态；路线颜色统一采用主题数据色。

使用 Astryx AppShell、TopNav、SideNav、Stack、Grid、Section、Table、Dialog、Collapsible、Banner 等组件。原有八份页面样式表已移除。日期、时间、文件及业务表单继续使用保留浏览器事件与约束的原生控件，外观由统一适配器和主题 token 提供，避免改变既有时间输入和保存行为。

主题源码为 `frontend/src/themes/suka/sukaTheme.ts`，色板、字体、圆角、移动适配与弹窗标题留白集中维护。`astryx-themes.ts` 由 CLI 管理。Astryx core、CLI 和基础主题固定为 0.7.15，依赖锁文件随代码提交。使用系统字体，不额外下载字体。

## 本机入口与开发

- 稳定版：<http://127.0.0.1:8000>，仍为原固定运行快照。
- 测试版：<http://127.0.0.1:8002>，使用独立源码、依赖、数据库、配置、道路参考缓存及 Cookie；使用测试副本中的已有账号登录。
- Vite 开发入口仅监听 `127.0.0.1:5173`，API、地图代理及健康检查固定转发到 8002，端口冲突即报错，不回退连接8000。

在 frontend 目录运行：

```bash
pnpm install --frozen-lockfile --store-dir ../.cache/pnpm
pnpm test
pnpm build
pnpm dev
```

dev、test、build 都先生成主题文件。生成的主题 JS、CSS、声明及前端 dist 不提交。测试快照更新遵循 [运行隔离说明](runtime-isolation.md)。

## 验证结果

- 全量后端：2,401 项通过；4 项第三方依赖弃用提示。
- 全量前端：19 个文件、121 项通过；最后的规划布局调整后再执行8个相关文件、52项，全部通过；历史列表最后调整的3个相关文件、20项也通过。
- TypeScript 与生产构建通过。Astryx 的客户端指令由 Vite 忽略；构建仍有大分块体积提示，不影响本机功能验收。
- 主数据真实浏览器：77 项断言通过，覆盖1440/390宽度、下载、搜索分页、行政区联动、地区报价与版本，以及门店营业起止时间单条/批量输入、清空重填、保存重载。
- 临时业务账号实际登录、刷新恢复会话、隐藏管理菜单及退出注销通过。共享任务新建、编辑、完成、恢复及刷新保留；临时账号创建、重置密码、停用、启用和删除；登录密码显示切换及移动导航打开、跳转和关闭均通过。
- 规划需求、资源、快照、历史、导出、固定道路样例、人工核算及移动导航共10组浏览器检查通过，规划业务表摘要不变。
- 全部页面1440/390宽度没有页面横向溢出，宽表在自身区域横滚；未发现浏览器页面异常。
- 地图真实底图、弹窗内全屏、退出全屏及失败提示验证通过。历史路线最终检查采用完全阻断外网的本地SDK桩，验证167段折线、6种实际RGB路线色和标记样式；没有向地图服务发送该轮历史轨迹数据，也不将此项声明为真实高德历史路线渲染验收。
- 稳定库26张表的逐行摘要、稳定前端资源摘要与改造前完全一致。测试会话即使改用稳定Cookie名也被稳定版拒绝。开发代理实测返回测试版标识。

浏览器证据、截图、日志和数据库摘要保存在本机忽略目录 `data/astryx-20261114/`，不上传业务资料。测试中修改的原门店时间已恢复，临时报价和任务已清理，临时账号已删除，专项会话已撤销。
