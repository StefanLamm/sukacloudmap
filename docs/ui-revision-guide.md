# 地图、管理页面与物流业务调整（v0.3.1）

> 后续进展：第四阶段每日需求与输入快照现已完成，见 [第四阶段说明](stage4-guide.md)。本文保留v0.3.1调整时的范围记录。

本轮根据四项修改要求调整现有应用，保留账号、稳定编号、既有资料、报价历史和当日安排。无需新增数据库迁移，当前版本仍为 `0002_master_data`。

## 四类管理页面

仓库、门店、车辆、报价方案仅维护本身资料和关联信息。页面、新增/编辑表单、新模板均不再要求配送日期；移除了当日安排、规划门店选择和兼容判断按钮。营业开始/结束与是否跨日营业仍是门店固定资料，属于经营时间信息。

车辆管理显示默认归属仓和默认可用性。仓库管理维护仓库地址、位置和默认信息。报价页面显示最新保存参数，修改即保存新版本，自动使用当前北京时间日期，不让维护人员选择业务日期。既有历史版本及兼容API保留原有生效日期，物流业务按所选配送日解析有效版本。

新版报价模板不再有「生效日期」，门店模板不再有「最晚到店日期时间」。旧文件的这两列仍可被兼容解析；不含业务日期的新门店主资料导入不会清空既有最晚到店值。后续每日业务限制统一在物流业务输入中维护。

管理数据接口为 `GET /api/master-data/management`，不受配送日期和当日资源覆盖影响；业务接口 `GET /api/master-data/catalog?delivery_date=...` 继续解析当天有效信息。

## 地图选择与关联位置

仓库、门店的新增/编辑表单均可选择位置，列表也提供独立「选择位置」入口：

1. 输入城市、街道或地点，点击「搜索位置」，选中结果后同步文字地址、经纬度、WGS84坐标系和来源。
2. 拖动地图寻找位置，点击地图选点，或拖拽橙色标记微调。也可点击「使用地图中心」。
3. 核对文字地址并保存。点击或拖拽不会自动改写地址文字，便于保留实际收货地址描述。
4. 在管理页切换「地图」，已关联仓库/门店显示为可点击标记，点击显示名称、编号和地址。搜索列表时地图也按搜索结果筛选。

地址文字可直接编辑；经纬度仍支持手工输入。尚未定位的记录显示未关联，不会在地图默认中心生成假位置。

底图使用OpenStreetMap，文字搜索使用Photon。手动搜索仅在点击按钮或回车时发出，输入过程不自动查询。v0.10新增仓库/门店导入后按地址后台自动关联，未精确匹配时标记需手动关联，详见 [新版说明](master-update/guide.md)。搜索文字和自动关联的地址发送至开放搜索服务。外部查询串行限速，缓存规范化查询24小时、最多256条；搜索失败可重试或继续地图选点。

新选点保存WGS84，并明确标记搜索/点击/拖拽来源。已有GCJ02或BD09坐标在地图显示时近似转换为WGS84，原始数据保持原坐标系；转换只用于点位显示，不是货车道路验证结果。没有高德密钥也可进行这一轮的位置维护。

需要能访问底图与搜索服务的网络。可通过 `.env` 更换兼容服务，无需重新编译：

```dotenv
SUKA_MAP_TILE_URL=https://tile.openstreetmap.org/{z}/{x}/{y}.png
SUKA_MAP_GEOCODER_URL=https://photon.komoot.io/api/
```

瓦片模板支持 `{z}/{x}/{y}`；替代搜索服务需兼容Photon GeoJSON响应。服务地址必须为不嵌入凭证的HTTPS地址。公共服务用于当前小规模内部交互；扩大使用时可配置自托管或有服务保障的兼容提供方。地图保留来源署名，浏览器按HTTP缓存请求瓦片，无离线批量下载或预抓取。

## 物流线路规划

侧栏新增独立「物流线路规划」板块，现有业务操作集中于此：

- 选择配送日期和出货仓库。
- 按日期设置仓库发车时间、车辆归仓和可用性。
- 查看当日有效报价、共配单价和缺失配置。
- 勾选门店进行同仓及完整参数兼容判断。
- 查看相关仓库与门店的位置地图。

当日覆盖不修改四类管理页面中的默认资料，也不影响其他日期或使已预览的主资料导入失效；它使用独立的当日修订号。普通业务账号可使用此板块，未登录仍被拦截。

接口中主资料使用 `master_revision`，当日安排使用各行 `day_revision`。后续S4输入快照需要同时纳入主资料与当日修订，不能仅凭主资料版本判断业务输入是否变化。

本轮完成业务入口与现有操作的分离，没有实现后续阶段的每日件数导入、完整线路求解、真实货车道路及执行方案导出。兼容判断不能作为实际执行线路。后续S4至S7的业务功能继续接在本板块。

## 视觉与验证

主体使用浅爱马仕橙色系，主要文字为深橙棕色；登录、导航、卡片、表格、弹窗、状态和图标统一更新。地图瓦片保留其自然配色，界面标记为橙色。

验证记录见 `ui-revision-validation.json`。原阶段报告和交接方案保留为历史记录。

实现依据：[Leaflet 1.9.4](https://leafletjs.com/reference-1.9.4.html)、[Photon项目与公共服务说明](https://github.com/komoot/photon)、[OpenStreetMap瓦片使用规则](https://operations.osmfoundation.org/policies/tiles/)、[坐标转换组件](https://github.com/wandergis/coordtransform)。
